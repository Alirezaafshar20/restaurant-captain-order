# MOYA Captain Order

منوی تعاملی و دستیار سفارش مویا، همراه با گردش کار مهمان، کاپیتان، آشپزخانه، صندوق و مدیریت.

این مخزن خصوصی است. نسخهٔ فعلی برای نمایش و آزمایش کنترل‌شده آماده شده؛ پنل‌ها پشت یک ورود مشترک قرار دارند. حساب مستقل کارکنان، مجوزهای واقعی هر کارمند، اتصال صندوق رستوران و پرداخت بانکی هنوز جزو این نسخه نیستند. لینک مهمان را قبل از افزودن کنترل دسترسی مستقل، عمومی نکنید.

## نصب روی هتزنر

راهنمای کامل نصب، به‌روزرسانی و نگهداری: [deploy/README.fa.md](deploy/README.fa.md).

- Ubuntu 22.04، Docker، Nginx و SQLite پایدار خارج از کانتینر.
- HTTPS معتبر برای IP عمومی، بدون نیاز به دامنه؛ امکان افزودن دامنه بعداً.
- انتشار از یک commit مشخص و کامل، ساخت و آزمون قبل از تغییر نسخهٔ فعال.
- کلید OpenAI فقط در `/etc/moya/app.env` روی سرور قرار می‌گیرد و وارد Git یا image نمی‌شود.
- داده‌های نسخهٔ میزبانی قبلی به‌صورت خودکار منتقل نمی‌شوند.

## توسعه و بررسی

Node.js 24.16.0 و نصب وابستگی‌ها از فایل قفل:

```bash
npm ci
npm run check:release
```

`npm run dev` و `npm run build` مسیر توسعه و انتشار قبلی Cloudflare/Sites را حفظ می‌کنند. `npm run build:node` خروجی مستقل Node را در `dist` می‌سازد؛ خروجی دو مقصد را به‌جای هم منتشر نکنید. فایل‌های محیط محلی در `.gitignore` هستند.

برای ارسال نسخهٔ جدید بعد از ثبت تغییرات در Git:

```bash
npm run push:github
```

این دستور وجود تغییر ثبت‌نشده را رد می‌کند، آزمون‌ها و ساخت را اجرا می‌کند و شناسهٔ commit ارسال‌شده به GitHub را بررسی می‌کند. دستور deploy با همان شناسه را نیز نمایش می‌دهد.
